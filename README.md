# Writing Guidelines

Tashi's personal writing standards, kept portable so they're usable from any repo or tool, not
just this Shared Drive.

Two documents, covering two different things:

- **[style.md](style.md)** — how writing *sounds*: word choice, punctuation, sentence rhythm.
  The goal is prose that reads as human-written, not AI-generated.
- **[fact-and-voice-rules.md](fact-and-voice-rules.md)** — what a draft is *allowed to claim*
  and *whose voice it's in*. Stricter, and applies specifically to anything another person will
  read or that describes a third party (outreach, letters, feedback, references).

Run both on anything substantive before it ships. Neither replaces the other.

## Using this elsewhere

Point a project's `CLAUDE.md` (or equivalent) at this repo, or copy the two files in directly.
The canonical, always-current copies of the equivalent rules also live in:

- `~/.claude/CLAUDE.md` (global writing style — source for `style.md`)
- The `ty-writing-rules` skill, where that's available (source for `fact-and-voice-rules.md`)

This repo exists so the same rules travel to places that don't have the skill or the global
config loaded.
